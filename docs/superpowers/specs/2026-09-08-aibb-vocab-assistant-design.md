# 词汇助手（Agent-LLM 领域词汇中台）设计

**状态：已由用户确认决策点，开发完成待验证。**

## 目标

在 AIbb 中新增一个「词汇助手」对话模式：用户左键点击悬浮窗后，弹出的对话窗先显示两个选择——原 AIbb 对话（逻辑不变）或词汇助手。词汇助手按用户提供的《Agent-LLM 词汇表构建・提示词技能包》作为系统提示词运行：输入英文术语 → 输出标准化词条块（音标/谐音/领域场景释义/词根拆分/V 编号/重复计数），累计 20 条独立词条时主动提醒导出表格并做初步大类规划。

用户可在右键设置里、AIBB 对话个性设置下方编辑「词汇助手大环境」，切换默认工作领域；词汇对话与普通聊天记忆互相隔离；「清除记忆」与「清除词汇词库」分开操作。

## 非目标

- 不在本地建词库表：V 编号、重复计数、20 条阈值全部由模型在对话上下文内维护（提示词驱动）。
- 词汇助手不参与出游意图分流：`agent`、`tool` 等术语绝不触发网络探索。
- 词汇对话不注入 AIbb 性格设定；使用技能包自身的角色定义。
- 不改动原 AIbb 对话、探索、归档的既有行为。

## 用户体验

### 模式选择

- 左键点击悬浮窗 → 对话窗打开即显示模式选择页（`chat://opened` 事件每次重开都会把窗口重置回选择页）。
- 两张选项卡：`💬 AIbb 对话`（原逻辑）与 `📚 词汇助手`。
- 进入任一模式后，窗口头部有「切换」按钮回到选择页；词汇模式头部还有「导出词表」按钮。

### 词汇助手对话

- 欢迎语：输入一个英文术语，按标准词条模板解析。
- 每条回复按技能包模板输出；模型维护虚拟词库编号与计数。
- 词汇历史独立回放（vocab 通道），与普通聊天历史互不混入。

### 导出词表

- 点击「导出词表」→ 后端把词汇对话交给模型「先梳理整理」（去重、连续编号、五列 Markdown 表格 + 统计）→ 写入应用数据目录 `vocab-export/词汇表-<毫秒时间戳>.md` → 返回文件路径与预览。
- 前端展示预览、完整路径与「复制路径」按钮。

### 设置页

- 在「性格定制」下方新增「词汇助手」区块：
  - 「词汇助手大环境」多行文本框（≤500 字，留空回退内置「Agent-LLM 开发」），随「保存/保存并测试」落库。
  - 「清除词汇词库」独立按钮（带确认弹窗），只清 vocab 通道；「清除记忆」只清 chat 通道、摘要与出游记录。

## 架构

### 记忆通道隔离

- 迁移：`messages` 表新增 `channel TEXT NOT NULL DEFAULT 'chat'`。
- `MemoryRepository` 读写方法带通道维度（`append_in` / `recent_messages_in` / `context_snapshot_in` / `unsummarized_before_recent_window_in` / `clear_vocab_memory`）；聊天包装器保持既有签名。
- 通道常量：`memory::CHAT_CHANNEL` / `VOCAB_CHANNEL`。
- 词汇通道不做摘要压缩；普通聊天摘要逻辑不变。

### 词汇服务

- `prompts.rs`：`VOCAB_SYSTEM_INSTRUCTION`（技能包原文，`{大环境}` 占位符）、`DEFAULT_VOCAB_ENV`、`VOCAB_EXPORT_INSTRUCTION`、`build_vocab_prompt(context, env)`。
- `ChatTaskRuntime` 增加 `TaskMode::{Chat{persona}, Vocab{env}}`：决定系统提示词、记忆通道、是否摘要。
- 新增 `VocabChatRuntimeFactory`（读设置 `vocab_env` + API Key + 模型）。
- `AppState` 增加 `vocab: Option<ChatService>`；`lib.rs` 用同一 `TauriChatEventSink` 构建。
- 新命令 `commands/vocab.rs`：`submit_vocab_input`（直进词汇聊天，绕开意图分流）、`load_vocab_history`、`export_vocab_glossary`。
- 设置命令：`clear_vocab_memory`。
- 事件复用 `chat://delta|complete|error`；新增 `chat://opened`（`toggle_chat` show 时 `emit_to("chat", ...)`）。

### 设置持久化

- 迁移：`app_settings` 新增 `vocab_env TEXT NOT NULL DEFAULT ''`。
- `ApiSettings`/`SaveSettings`/`PersistedSettings` 增加 `vocab_env`；`validate_vocab_env` 限 500 字；保存回滚链路同步。

### 前端

- `contracts.ts`：`vocabEnv`、`VocabExportResult`。
- `lib/tauri.ts`：`submitVocabInput` / `loadVocabHistory` / `exportVocabGlossary` / `clearVocabMemory` / `listenChatOpened`。
- `ChatPanel`：`mode` 状态（`chat`/`vocab`/`null`=选择页），`defaultMode` 测试注入；模式切换时回放对应通道历史；词汇模式发送走 `submitVocabInput`；导出面板。
- `SettingsPanel`：词汇助手区块 + 独立清除确认弹窗。

### 权限

- `chat.json`：`allow-submit-vocab-input` / `allow-load-vocab-history` / `allow-export-vocab-glossary`。
- `settings.json`：`allow-clear-vocab-memory`。
- `permissions/autogenerated/*.toml` 同步新增；`lib.rs` 权限断言测试更新。

## 验收条件

1. 左键点击悬浮窗 → 对话窗显示「AIbb 对话 / 词汇助手」两个选择；每次重开都回到选择页。
2. 选择 AIbb 对话 → 原行为不变（聊天、出游、归档照旧）。
3. 选择词汇助手 → 输入 `agent` 得到标准化词条块；再输入 `agent` 命中重复计数，不新增编号；输入不触发出游。
4. 词汇历史重开可回放，且与普通聊天历史互不混入。
5. 设置页「词汇助手大环境」保存后，下一条词条提示词注入该环境；留空回退 Agent-LLM 开发。
6. 「导出词表」先整理后落盘，返回路径与预览；文件在应用数据目录 `vocab-export/`。
7. 「清除词汇词库」只清词汇对话；「清除记忆」不动词汇对话。
