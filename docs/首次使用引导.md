# AIbb 首次使用引导

> 写给第一次打开 AIbb 的你：一分钟看完，就能把它玩起来。

---

## 👋 欢迎

AIbb 是一只停留在你桌面角落的 AI 小宠物。它会陪你聊天、记住你说过的话，还会在你说「去玩」时自己出门上网逛一圈，把发现写成日记讲给你听。

所有对话、记忆、归档记录都只保存在这台电脑上。

---

## ⚠️ 第一步：必要配置（不做就用不了）

**AIbb 的聊天和出门探索都需要一个 AI 接口密钥。** 不配置的话，点它只会沉默。

1. 打开 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 **API Key**（也支持其他兼容 OpenAI 的服务）
2. 右键宠物 → **设置** → 粘贴 API Key（API 地址和模型会自动填好）
3. 点 **「保存并测试」**，提示连接成功即可开始使用

> 密钥只保存在本机系统凭据里（Windows 凭据管理器），应用内不落盘明文，不会上传任何服务器。

---

## 🎨 第二步：可选配置（按喜好来）

| 配置 | 在哪 | 说明 |
| --- | --- | --- |
| 昵称 | 设置 | 给 AIbb 起个名字，它会有归属感 |
| 头像 | 设置 | 上传图片，宠物、托盘、桌面图标全部同步成圆形头像 |
| 性格 | 设置 | 选一套人设（活泼元气 / 温柔治愈 / 毒舌傲娇…）或手写你自己的设定，聊天和日记都按这个性格说话 |
| 开机自启 | 设置 | 让 AIbb 每次开机自己出现 |
| 窗口置顶 | 设置 | 悬浮窗始终在其他窗口之上 |
| 归档目录 | 归档面板 | 设置文件归档的目标文件夹与规则 |

---

## 🐾 第三步：桌宠怎么操作

| 操作 | 效果 |
| --- | --- |
| **点击**宠物 | 打开聊天窗 |
| **长按并拖动** | 移动悬浮窗，松手自动吸附屏幕边缘，不会被拖出屏幕 |
| **右键**宠物 | 打开设置 |
| **拖文件到宠物身上** | 按规则自动归档到项目目录（见下节「📁 文件归档」） |

---

## 📁 文件归档（文档归类）

AIbb 会帮你**整理文件**：把文件往宠物身上一拖，它自动按你的规则归类到归档目录，原文件保留不动。

**怎么开始（三步）**：

1. 打开**归档面板**（设置 → 归档），指定一个**归档目录**（例如你的项目文件夹）
2. 可选：设置**关键词规则**（比如「带"发票"的文件 → 财务」），或从**结构库模板**选择现成分类
3. 把任意文件**拖到宠物身上** → AIbb 自动判断该归到哪，移入归档区并记入台账

**它怎么归类**：

- **自动识别**：自动发现归档区已有的文件夹结构，新文件跟着现有分类走
- **关键词规则**：按你写的规则把文件分到对应分类
- **周/分类层级**：支持按「X月第N周」「YYYY-MM」等周、月层级归档
- **结构库模板**：用现成模板快速搭好分类骨架
- **防重复**：归档区已有完全相同的文件时会拒绝，避免重复归档

> 归档只移动（或记录）文件到归档区，**不会删除或改动你的原文件**；归档台账随时可查。

---

## 🧭 第四步：它能陪你做什么

- **陪聊**：像朋友一样说话，有温度、会配表情；聊到兴头上还会偷偷溜出去逛一圈，把有趣的链接和图片带回来
- **出门探索**：对它说「去玩」「出去玩」「出发」，它会自主上网搜索、阅读，带回一篇**4 个方向**的探索日记（带来源链接和图片），结尾还有总结金句；也可以指定方向，比如「往天文学方向玩」
- **换着花样逛**：每一轮都会主动换一条不同的路线，不会老逛同一个地方
- **长期记忆**：它会记住你们的对话；记忆会被压缩整理，但绝不会被一刀切删除
- **出游记录**：每次出游都会记数（聊天窗口顶部 🐾 ×N），重开窗口能看到历史日记卡片
- **托盘**：右下角状态栏图标左键开关聊天窗，右键菜单「显示 AIbb / 退出」

---

## 🔒 数据与隐私

- **API Key**：仅存于系统凭据库，不落盘明文
- **对话 / 记忆 / 探索记录 / 归档台账**：全部存在本机 SQLite（`com.clink.aibb` 配置目录）
- **联网**：只在你说「去玩」或聊天触发探索时访问公开网页；无遥测、无账号、无云同步

## ❓ 遇到问题

- 首次打开如遇 SmartScreen「未知发布者」提示：点「更多信息 → 仍要运行」
- 右键宠物 → 设置里可测试连接；排查时带上：Windows 版本、AIbb 版本、复现步骤与报错文案
